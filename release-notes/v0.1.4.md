## Windows 설치 수정
- 관리자 권한으로 실행해도 "모든 사용자" 설치가 실패하던 문제를 고쳤습니다.
- 설치 파일이 Downloads나 임시 폴더에 있어도 상승된 관리자 계정이 읽을 수 있도록, 접근 가능한 위치에 복사한 뒤 승격합니다.
- 이미 관리자 권한으로 실행 중이면 UAC를 다시 요청하지 않고 바로 모든 사용자 설치를 진행합니다.
- 권한을 얻지 못하면 자동으로 "나만 사용"으로 전환됩니다.

## 터미널 설치
- **macOS · Linux**: `curl -fsSL https://zip.dapercorp.com/install.sh | sh`
- **Windows**: `winget install DaperCorp.DaperZip` (winget-pkgs 검토 중)

## macOS
- 이번 빌드도 아직 공증 전입니다. 처음 실행할 때 경고가 나오면 시스템 설정 → 개인정보 보호 및 보안에서 "확인 없이 열기"를 누르세요.
- `curl` 설치 스크립트로 받으면 격리 표시가 붙지 않아 경고를 피할 수 있습니다.

## 다운로드
- **Windows**: `DaperZip_0.1.4_x64-setup.exe` 또는 `DaperZip-portable-windows-x64.zip`
- **macOS**: `DaperZip_0.1.4_universal.dmg`
- **Linux**: `.deb` 또는 `.AppImage`

Windows 코드 서명 전이라 SmartScreen 경고가 나올 수 있습니다.
