DaperZip 첫 베타 버전입니다. 압축 처리는 7-Zip 26.04 엔진을 사용합니다.

## 다운로드
- **Windows**: `DaperZip_0.1.0_x64-setup.exe` (설치형: "나만 사용" / "모든 사용자" 선택) 또는 `DaperZip-portable-windows-x64.zip`
- **macOS**: `DaperZip_0.1.0_universal.dmg` (Apple Silicon / Intel)
- **Linux**: `.deb` 또는 `.AppImage`

## 주요 기능
- 7-Zip이 지원하는 형식 열기/풀기 (ZIP, 7Z, RAR, TAR, GZ, XZ, ISO 등)
- ZIP, 7Z, TAR.GZ/XZ/BZ2 압축, 비밀번호(AES-256), 분할 압축
- 스마트 풀기, 압축 파일 안의 파일 추가/삭제/이름 바꾸기
- Windows 탐색기 오른쪽 클릭 메뉴
- 드래그로 여러 파일 선택, Ctrl+C로 복사해 탐색기에 붙여넣으면 고른 항목만 풀기
- Mac에서 만든 압축 파일의 한글 이름 깨짐 방지, 옛 Windows(CP949) ZIP 자동 인식
- 마우스 이전/다음 버튼 탐색, 업데이트 알림, 한국어/English

## 알려진 사항
- 코드 서명 전이라 Windows에서 SmartScreen 경고가, macOS에서 "확인되지 않은 개발자" 경고가 나올 수 있습니다.
  - Windows: "추가 정보 → 실행"
  - macOS: Finder에서 오른쪽 클릭 → 열기
- Windows 11에서는 오른쪽 클릭 메뉴가 "추가 옵션 표시" 안에 있습니다.
