## 연결 프로그램 · 기본 앱 (Windows)

- 설치할 때 DaperZip이 압축 파일의 "연결 프로그램"과 Windows "기본 앱" 목록에 자동으로 등록됩니다. (.7z, .zip, .rar, .tar, .gz, .iso 등)
- 모든 사용자용으로 설치하면 모든 계정에, "나만 사용"으로 설치하면 현재 계정에 등록됩니다.
- 설치 완료 화면에 **기본 앱으로 설정** 버튼을 추가했습니다. Windows 기본 앱 화면에서 DaperZip을 선택하면 압축 파일이 DaperZip으로 열립니다.
- Windows 정책상 기본 앱은 사용자가 직접 한 번 선택해야 합니다. 설치 프로그램이 몰래 기본값을 바꾸는 방식은 사용할 수 없습니다.
- 설정의 "기본 앱 설정 열기"도 DaperZip 페이지로 바로 열립니다.

## 다운로드
- **Windows**: `DaperZip_0.1.7_x64-setup.exe` 또는 `DaperZip-portable-windows-x64.zip`
- **macOS**: `DaperZip_0.1.7_universal.dmg`
- **Linux**: `.deb` 또는 `.AppImage`

Windows 코드 서명 전이라 SmartScreen 경고가 나올 수 있습니다.
