## Windows 설치 프로그램

- 설치 폴더에 보이던 `unins000.exe`, `unins000.dat` 제거 파일을 기본적으로 숨김 처리했습니다.
- 설치 폴더와 시작 메뉴에 **DaperZip 제거** 바로가기를 추가했습니다. (영문: Uninstall DaperZip)
- 바로가기는 DaperZip 아이콘을 사용하며, 누르면 기존과 같이 Windows 제거 프로그램이 실행됩니다.
- Inno Setup이 제거 파일 이름을 고정하기 때문에 파일 자체의 이름은 유지합니다. 대신 보기 좋은 바로가기와 숨김 처리로 정리했습니다.

## 다운로드
- **Windows**: `DaperZip_0.1.8_x64-setup.exe` 또는 `DaperZip-portable-windows-x64.zip`
- **macOS**: `DaperZip_0.1.8_universal.dmg`
- **Linux**: `.deb` 또는 `.AppImage`

Windows 코드 서명 전이라 SmartScreen 경고가 나올 수 있습니다.
