## Windows 설치 프로그램

- 설치 프로그램을 시작할 때 관리자 권한을 요청하도록 바꿨습니다. 권한을 허용하면 모든 사용자에게 설치되고, 거부하면 "나만 사용"으로 이어서 설치할 수 있습니다.
- 관리자 권한으로 실행해도 "모든 사용자" 설치가 실패하던 문제를 고쳤습니다. Inno Setup 6.4 이상에서 설치 프로그램이 자기 자신을 실행하지 못하던 부분을 cmd.exe를 거치도록 수정했습니다.
- "모든 사용자"를 선택한 채 권한이 없을 때의 안내 문구를 실제 동작에 맞게 다듬었습니다.
- 설치 대상 선택을 둥근 버튼으로 바꾸고, 선택한 항목이 강조되도록 했습니다. 설치 버튼과 하단 문구의 아래 여백도 넓혀 화면이 더 여유롭게 보입니다.

## 다운로드
- **Windows**: `DaperZip_0.1.6_x64-setup.exe` 또는 `DaperZip-portable-windows-x64.zip`
- **macOS**: `DaperZip_0.1.6_universal.dmg`
- **Linux**: `.deb` 또는 `.AppImage`

Windows 코드 서명 전이라 SmartScreen 경고가 나올 수 있습니다.
