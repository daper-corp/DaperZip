## 새 설치 프로그램 (Windows)
- 한 화면에서 설치 대상(**모든 사용자** 기본 / 나만 사용), 설치 위치, 오른쪽 클릭 메뉴, 바탕 화면 바로 가기를 고르고 바로 설치합니다.
- "모든 사용자"는 설치 버튼을 누를 때 관리자 권한을 요청합니다.
- WebView2가 없는 PC에서는 자동으로 함께 설치합니다.
- 0.1.0이 설치된 PC에서는 이전 설치를 정리하고 새로 설치합니다.
- 다음 버전부터는 업데이트가 진행 막대만 잠깐 보인 뒤 끝나고, DaperZip이 다시 실행됩니다.

## 그 밖의 변경
- 앱 화면을 dapercorp.com과 같은 색감으로 다듬었습니다.
- 정보 창의 웹사이트 주소를 zip.dapercorp.com으로 바꿨습니다.

## 다운로드
- **Windows**: `DaperZip_0.1.1_x64-setup.exe` 또는 `DaperZip-portable-windows-x64.zip`
- **macOS**: `DaperZip_0.1.1_universal.dmg`
- **Linux**: `.deb` 또는 `.AppImage`

코드 서명 전이라 Windows SmartScreen, macOS 보안 경고가 나올 수 있습니다.
