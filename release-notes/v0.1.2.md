## 업데이트 설치 수정 (Windows)

- 0.1.0(NSIS)에서 업데이트할 때 사용자별 설치를 "모든 사용자"로 잘못 판단해 관리자 권한을 요구하고, 권한이 없으면 설치가 중단되던 문제를 고쳤습니다.
- 이제 기존 설치 범위(나만 사용 / 모든 사용자)를 자동으로 따라갑니다. 사용자별 설치였던 PC는 관리자 권한 없이 업데이트됩니다.
- NSIS 시절의 설치본도 업데이트 대상으로 인식합니다.
- 설치 창을 제목 표시줄의 X나 Alt+F4로 닫을 수 있습니다.

## 다운로드
- **Windows**: `DaperZip_0.1.2_x64-setup.exe` 또는 `DaperZip-portable-windows-x64.zip`
- **macOS**: `DaperZip_0.1.2_universal.dmg`
- **Linux**: `.deb` 또는 `.AppImage`

코드 서명 전이라 Windows SmartScreen, macOS 보안 경고가 나올 수 있습니다.
