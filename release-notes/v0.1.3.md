## Windows 설치 프로그램
- 관리자 권한이 없는 계정에서도 설치됩니다. 새로 설치할 때 계정 권한에 맞춰 기본값이 정해집니다(관리자 계정은 "모든 사용자", 일반 계정은 "나만 사용").
- "모든 사용자" 설치 중 관리자 권한을 얻지 못하면 자동으로 "나만 사용"으로 전환되어, 설치 버튼을 다시 누르면 바로 설치됩니다.
- 설치 화면의 카드, 버튼, 입력란과 창 모서리를 둥글게 다듬었습니다.

## macOS
- Apple Developer ID 서명·공증을 CI에 연결했습니다. 저장소에 인증서 secrets가 등록되면 다음 빌드부터 자동으로 서명·공증됩니다.
- 이번 빌드는 아직 공증 전이라 처음 실행할 때 Gatekeeper 경고가 나옵니다. macOS 14 이하는 Finder에서 오른쪽 클릭 → "열기", macOS 15 이상은 시스템 설정 → 개인정보 보호 및 보안에서 "확인 없이 열기"를 누르세요.
- 터미널에서 `xattr -dr com.apple.quarantine /Applications/DaperZip.app`을 실행해도 됩니다.

## 다운로드
- **Windows**: `DaperZip_0.1.3_x64-setup.exe` 또는 `DaperZip-portable-windows-x64.zip`
- **macOS**: `DaperZip_0.1.3_universal.dmg`
- **Linux**: `.deb` 또는 `.AppImage`

Windows 코드 서명 전이라 SmartScreen 경고가 나올 수 있습니다.
